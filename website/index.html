从本地推理到 LoRA 微调，从语音合成到 3D 渲染，小凌拥有完整的生命闭环。

Flutter 粉色界面

左侧边栏导航，粉金玻璃质感，与 Python 后端通过 gRPC 解耦。

本地 LLM 推理

LoRA 微调成长
