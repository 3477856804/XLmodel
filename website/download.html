核心能力

🧠 自主 Agent 引擎
任务规划 → 工具调用 → 结果观察 → 迭代执行，完整事件流可视化。支持子 Agent 委派、MCP 协议、代码搜索、终端、文件操作。
🔌 万物皆插件
标准化插件 SDK，热加载/卸载/依赖管理。小凌社区插件市场，兼容 DeepSeek Harness (DSH) 插件生态。
💬 多平台消息通道
Telegram / Discord / 飞书 / WhatsApp / Slack / Signal / Webhook，一个 AI 遍布所有聊天平台。
🎯 LoRA 模型训练
自定义数据集导入、实时训练进度、Loss 曲线、训练历史。让 AI 真正学会你的风格。
🌱 成长与人格系统
亲密度、等级、情绪、五维能力成长。自定义人格创建，AI 不只是工具，更是伙伴。
🔐 安全与权限中心
工具权限开关、受保护目录、操作审计日志、危险操作审批。安全可控的自主执行。
⚡ 无代码工作流
可视化节点编排，触发器 → 动作 → 条件 → LLM 调用，自动化你的日常工作流。
📚 项目知识库 RAG
自动索引项目文档，TF-IDF 智能检索，AI 理解你的整个项目上下文。
🎨 新拟态视觉体系
粉金黑白配色，凹进去 3D 新拟态感，深色/浅色双主题，全页面细腻动效。
