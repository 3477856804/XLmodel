Quick Start

快速开始

3 步，让小凌住进你的设备。

1

克隆仓库

git clone https://gitee.com/COSMOnb666/XLmodel.git
cd XLmodel
2

安装依赖

pip install -r requirements.txt
3

启动小凌

python xl.py # Windows 桌宠
python3 xl.py # Linux/macOS 命令行
python xl.py --platform wechat,qq,telegram # 接入平台
