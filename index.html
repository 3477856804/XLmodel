CORE FEATURES

不只是桌宠，是数字生命

从 3D 渲染到本地推理，从语音合成到蒸馏训练，小凌拥有完整的生命闭环。

3D

纯 Python 3D 渲染

自研软件渲染器，支持 VRM/VRMA 模型加载、蒙皮变形、弹簧骨骼，无需 OpenGL 也能流畅运行。

AI

本地模型推理

内置 DeepSeek 蒸馏训练引擎，基底模型 + LoRA 适配器持续成长，完全离线运行，数据不出本地。

插件

万物皆插件

深度对话、Agent 任务、定时提醒、通话模式、语音朗读、蒸馏训练——每个功能都是可插拔的插件。

语音

专属音色绑定

每个角色模型绑定一套专属语音，开启阅读模式后，桌宠会用自己的声音朗读回复内容。

训练

可视化训练工作台

训练过程实时可视化，感知/理解/决策/进化/守护五维进度卡，角色在中央实时展示训练状态。

跨平台

三平台单文件

Windows .exe / Linux .tar.gz / macOS .zip，单文件双击即开，所有依赖（含 torch）已打包。
