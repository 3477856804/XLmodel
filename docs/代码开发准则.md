# 小凌 · 代码开发准则

## 架构
- Flutter (Dart) → gRPC → Python (AI后端)
- 三语言分离：frontend/ UI，backend/ AI，shared/proto/ 通信契约

## 命名规范
- 目录和文件用英文小写
- 类名用大驼峰
- 函数和变量用小写下划线
- 代码里不能有 emoji

## 模块组织
- backend/core/ 核心 AI 模块
- backend/renderer/ 3D 渲染引擎
- backend/rpc/ gRPC 服务
- frontend/lib/ Flutter UI

## 平台兼容
- 业务代码不能硬编码 Windows/Linux/macOS
- 用 platform.py 检测平台

## 提交规范
- 每次提交一个功能点
- commit message 格式：v0.0.4: 功能描述
