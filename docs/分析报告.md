## 4. 已实现能力（见 [`features.json`](features.json)）

- **3D 数字人桌宠**（`renderer/`）：VRM 解析/骨骼蒙皮/VRMA 动作/透明置顶窗，全 Python，含软件光栅兜底
- **2D 桌宠兜底**（`pet.py`）：Tkinter 程序化绘制，不依赖视频素材；无图形环境降级为命令行
- **成长闭环引擎**（`core/growth.py`）：训练→三条件评估→合并晋升→基底退役→适配器晋升，原子化合并 + 校验回滚
- **训练数据仓库**（`core/growth_store.py`）：SQLite 记录结构 + 质量分 + 哈希向量去重 + DPO 偏好对 + 加密导出
- **晋升三条件评估**（`core/eval.py`）：A 体积 + B 用户专属验证集 loss + C 通用基准（常识 20/通用 20/安全 10）
- **动态升 rank**（`core/rank.py`）：旧权重复制保留、新增补零、上限 256；自带 safetensors 纯 numpy 读写
- **模型生命周期**（`core/lifecycle.py`）：trash 退役 + 24h/100 轮稳定期 + 保留代数 GC + 回滚 + 导出 + 增长上限
- **蒸馏节流与成本**（`core/throttle.py`）：hash 缓存 / 每日限流 / 开关 / 用量与费用估算（单价可配置）
- **显存分级算力策略**（`core/device.py`）：<4GB 纯 CPU / 4~8GB 4bit 部分层 / >8GB 全 GPU，训练参数随档位自适应
- **LoRA 蒸馏训练器**（`core/peft_train.py`）：续训已有适配器、4bit 量化、梯度累积、损失曲线落盘
- **本地记忆检索**（`core/rag.py`）：SQLite + 向量召回
- **多平台接入**（`core/fusion.py`）：微信/飞书/QQ/企微/钉钉/Telegram/Discord 配置化接入
- **全系统体检**（`core/selftest.py`）：依赖/模型/形象/渲染层/记忆/磁盘一键体检
- **3D 工作台与成长可视化**（`renderer/dashboard.py`）：进度条/角色切换/蒸馏按钮/设置页；成长数据接口已对齐仪表盘
- **Android APK 打包**（`packaging/termux`）：Termux/Chaquopy 打包脚本与说明齐备，APK 需在本地环境实际构建后分发

## 6. 已知边界（诚实说明）

1. **晋升条件 B/C 需要 torch**：无 torch 时评估返回"未评估"而非"通过"，
   不会放行晋升；演练模式（`--dry-run`）会标注 `simulated: true`。
2. **费用估算单价为示例值**：`growth.teacher_price_in/out` 默认 1/2 元每百万 token，
   非官方报价，仅为本地估算，请自行改为实际资费。
3. **Android APK 需本地构建**：打包脚本与说明齐备，仓库不附带构建产物。
4. **授权限制**：`models/` 基底授权为 `Redistribution_Prohibited`，
  改造产物仅供本地自用，请勿再分发。
