# 小凌 · v0.0.4 开发计划（基于实际源码修订版）

> **目标**：Flutter(UI) + Python(AI后端) + gRPC(通信) 三语言分离架构落地，
> 从 xl.py 7199行巨石中解耦，模型 FBX 化，产出各平台正式安装包。
> **基线**：Gitee main @ 最新（xl.py 7199行 + core/26模块 + renderer/20文件）
> **原则**：架构解耦为主，新功能放后续版本，不一口吃成胖子。

---

## 一、当前代码现状（实测盘点）

| 模块 | 实际情况 | 规模 |
|---|---|---|
| `xl.py` | 巨石文件，UI+逻辑+渲染全混在一起 | 7199行 / 339KB |
| `core/` | 26个 Python 模块，AI 核心逻辑 | 832KB |
| `renderer/` | 20个 Python 文件，其中9个是 PySide6 UI | 716KB |
| `rpc/` | 已有 proto 定义 + gRPC server 骨架 | 44KB |
| `flutter/` | 只有 main.dart + updater.dart 骨架 | 28KB |
| 模型 | 7个 VRM + 1个 FBX（ty.fbx） | 195MB |
| `.star_core/` | LoRA 适配器权重（不是完整基座模型） | 45MB |
| 目录 | 中英文重复目录 8 对，空目录 3 个 | — |

### 实际已有的功能模块（core/ 26个）
- AI: fusion（对话融合）、growth（成长）、peft_train（LoRA训练）、rag、asr、tts、voices、lipsync、perception、proactive、reminder、search、vision、imagen
- 基础: config、paths、platform、lifecycle、device、eval、rank、throttle、filebox、selftest、avatar
- UI残留: launcher_ui（PySide6启动器，要删）

### 实际已有的渲染模块（renderer/ 纯渲染11个）
renderer、soft（软件光栅）、gl（OpenGL）、model、fbx_loader、gltf、vrma、pose、camera、i18n、lipsync

### 实际要删的 PySide6 UI（9个）
app、window、dashboard（1820行）、chat_ui、settings、startup_ui、theme、wizard、launcher_ui

## 二、v0.0.4 核心目标（只做这些）

**不是全量重写，是架构解耦 + UI 替换。**

| 做什么 | 说明 |
|---|---|
| 1. 三语言目录分离 | frontend/(Dart) + backend/(Python) + shared/proto/ |
| 2. 删 PySide6 UI | 9个文件全删，Flutter 重写 |
| 3. Flutter UI 核心页面 | 桌宠窗 + 工作台 + 聊天 + 设置 + 启动画面 |
| 4. gRPC 通信完善 | 现有 proto 补全，所有功能走 gRPC |
| 5. 模型 FBX 化 | 7个 VRM 转 FBX |
| 6. 智能模型商店 | 硬件检测 + 推荐 + 下载 |
| 7. 三平台安装包 | Windows .exe / macOS .dmg / Linux .AppImage |
| 8. 自动更新 | 三平台增量更新 |
| 9. 仓库结构整理 | 中文目录改英文，重复目录合并 |
| 10. 跨平台代码规范 | 业务代码零平台名硬编码 |

**v0.0.4 不做的（放 v0.0.5+）：**
- 持久记忆系统（5层记忆）
- 拟人化人格系统（大五人格/情绪状态机）
- 全平台通信（微信/QQ/Telegram等）
- 插件市场
- 真实训练管线重做
- DPO/奖励模型

这些是 v0.0.5 / v0.0.6 的事，v0.0.4 先把架构搭稳。

## 三、三语言分工

| 语言 | 管什么 | 目录 |
|---|---|---|
| **Dart (Flutter)** | 所有 UI 界面、用户交互、动画 | `frontend/` |
| **Python** | AI 推理、3D 渲染、模型管理、业务逻辑 | `backend/` |
| **Proto (gRPC)** | 前后端通信契约 | `shared/proto/` |

```
frontend/ (Dart) → gRPC → shared/proto → gRPC → backend/ (Python)
```

## 六、核心任务详情

### M0：基础设施 + 目录整理（2周）
- 三语言目录拆分：frontend/ backend/ shared/
- 中文目录全部改英文，重复目录合并
- 新增 `backend/core/platform.py` 跨平台检测
- 新增 `backend/core/hardware.py` 硬件检测
- 新增 `backend/core/model_store.py` 模型下载
- 删除 PySide6 UI 文件（9个）
- 删除空目录和废弃文件

### M1：FBX 模型迁移（2周）
- 7个 VRM 模型用 Blender/VRM Converter 导出为 FBX
- `renderer/model.py` 补 Mixamo 骨骼别名映射
- assimp 打包进安装包
- 动作资产转 FBX 动画片段

### M2：Flutter UI 核心页面（3周）
- 6个页面：启动/桌宠窗/工作台/聊天/设置/模型商店
- 粉色少女风主题：奶油渐变 + 玻璃卡片
- Riverpod 状态管理
- gRPC 客户端接入

### M3：gRPC 后端完善（2周）
- 现有 proto 补全方法：音色/插件/设置/硬件检测/模型下载
- Python 渲染帧 → gRPC 流式 PNG → Flutter 显示
- Flutter 自动拉起/关闭 Python 子进程
- 端口冲突自动回退

### M4：智能模型商店（2周）
- 硬件检测：VRAM/RAM/CPU/磁盘
- 推荐算法：过滤能跑的 → 质量评分排序 → "推荐"标签
- 下载源：ModelScope（37MB/s）主，hf-mirror 备
- 断点续传 + SHA256 校验 + 排队下载

### M5：三平台安装包（3周）
- Windows：NSIS .exe 安装包
- macOS：.dmg 磁盘映像
- Linux：.AppImage
- 内置所有依赖（含 torch CPU 版）

### M6：自动更新（1周）
- Windows：自解压差分补丁
- macOS：Sparkle
- Linux：AppImageUpdate
- 差分包增量更新 + 回滚

### M7：全平台实测 + 发布（2周）
- Windows/macOS/Linux 三平台实测
- 官网更新下载链接
- 版本号 v0.0.4 发布
