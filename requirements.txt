#
# ⚠️ 重要：torch 默认装的是 **CPU 版**（`torch.__version__` 带 `+cpu` 后缀），
#    即使机器有 NVIDIA 独显，`torch.cuda.is_available()` 也会是 False，
#    成长训练会静默退回 CPU（0.5B 模型 2 steps 约 3 分钟）。
#
#    要用GPU，装 CUDA 版（版本号需与你的 CUDA 匹配，下面以 13.0 为例）：
#        pip install torch==2.14.1+cu130 \
#            --index-url https://download.pytorch.org/whl/cu130
#        # 国内网络不稳时用断点续传下到本地再装（pip 不支持续传，断了要重来）：
#        curl -L -C - --retry 20 --retry-all-errors \
#          -o torch-2.14.1+cu130-cp3xx-cp3xx-win_amd64.whl \
#          "https://download.pytorch.org/whl/cu130/torch-2.14.1%2Bcu130-cp3xx-cp3xx-win_amd64.whl"
#        pip install --no-index --no-deps .\torch-2.14.1+cu130-cp3xx-cp3xx-win_amd64.whl
#
#    CUDA 版本索引对照：cu126 / cu128 / cu130，RTX 50 系（Blackwell, sm_120）需 cu130。
#    装完自查：python -c "import torch; print(torch.__version__, torch.cuda.is_available())"
